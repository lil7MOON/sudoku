# 经典数独 🎯

一个开箱即用的网页版数独游戏，全部代码集中在单个 `index.html` 文件里 —— 无需安装、无需构建、无需联网，双击就能玩。

支持 10 个难度递增的关卡、计时与星级评分、每关 3 次提示、错误高亮、同数字联动高亮，以及用 Web Audio API 实时合成的操作音效。

## 快速开始

**方式一：直接打开**

双击 `index.html`，用浏览器打开即可。

**方式二：本地静态服务器（推荐）**

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8000>。

> 推荐用服务器方式打开：部分浏览器对 `file://` 协议下的页面有额外限制，用 http 访问体验更稳定。

## 功能特性

- **10 个关卡，难度递增**：从 51 个已知数字逐步挖空到 24 个，越往后越烧脑。
- **自动出题，且保证唯一解**：每局用随机回溯算法生成完整解，再逐格挖空并实时校验唯一性，同一关每次重开都不一样，且永远只有一种标准答案。
- **星级评分**：按用时给 1～3 星，三星阈值随关卡提高。
- **提示系统**：每关 3 次提示，自动为随机空格填入正确答案。
- **即时反馈**：填入重复数字立刻标红；「检查」按钮可一键找出与答案不符的格子。
- **智能高亮**：选中格子后，同行、同列、同宫以及相同数字会自动高亮。
- **关卡进度**：通关后解锁下一关，已通关卡显示 ✓，可随时回退重玩。
- **键盘操作**：方向键移动、数字键填数、退格擦除。
- **音效**：基于 Web Audio API 合成，无音频文件依赖。
- **响应式布局**：手机、平板、桌面自适应，附带移动端数字面板。

## 游戏规则

在 9×9 的棋盘中填入数字 1–9，使得：

1. 每行 9 个格子包含 1–9，不重复；
2. 每列 9 个格子包含 1–9，不重复；
3. 每个 3×3 宫格包含 1–9，不重复。

## 实现说明

**出题**：`generateSudoku()` 用回溯法逐格填入随机顺序的合法数字，得到完整解；`createPuzzle()` 再逐格挖空 —— 每挖掉一格都会用 `countSolutions()` 确认题目**仍然只有唯一解**，会多解的格子立刻填回去。若某次挖空顺序没挖到目标数量，会换个顺序重试（最多 20 次），取挖得最多的一次。<br>
**唯一解校验**：`countSolutions()` 是位运算 + 最少候选数（MRV）优先的回溯求解器，找满 2 个解就提前退出，单次判断通常在 1 毫秒内。<br>
**校验**：填入时调用 `checkConflicts()` 做行/列/宫冲突检测；`checkSolution()` 与完整解逐格比对 —— 因为题目保证唯一，比对完整解即等价于比对唯一正解。<br>
**提示**：从所有空格或填错的非已知格中随机挑一个，填入完整解对应数字。

## 已知限制

- **进度不持久化**：关卡进度和星级只存在内存里，刷新页面或返回首页重新开始会清空。如需保存，可以用 `localStorage` 挂接到 `completedLevels` 和 `levelStars` 上。
- **难度由挖空数决定，未按解题技巧分级**：题目保证唯一解，但「需要用到哪种推理」没有做评估，所以同一关偶尔会出现体感偏难/偏易的题。
- **不支持笔记模式**（候选数标记）。

## 可扩展方向

- 用 `localStorage` 保存进度与最佳成绩
- 按解题技巧（唯一候选、数对、区块排除等）给题目分级，而不是只看挖空数
- 增加笔记模式、撤销上一步
- 抽离内联脚本/样式到独立文件，接入 Vite 之类的构建工具
